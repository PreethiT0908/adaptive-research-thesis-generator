🚀 START THE APPLICATION (Choose One)

  Windows Command Prompt:
  $ start-dev.bat

  Windows PowerShell:
  $ .\start-dev.ps1

  Manual (Terminal 1):
  $ cd app
  $ python api.py

  Manual (Terminal 2):
  $ cd thesis-frontend
  $ npm run dev


🌐 ACCESS THE APPLICATION

  Frontend:        http://localhost:5173
  Backend API:     http://localhost:8001
  API Docs:        http://localhost:8001/docs


📋 QUICK WORKFLOW

  1. Start both services (see above)
  2. Open http://localhost:5173 in browser
  3. Fill in the thesis generation form:
     - Degree (UG/Master/PhD)
     - University name
     - Discipline
     - Research topic
     - Target journal (optional)
  4. Click "Generate Thesis"
  5. View results


🔧 TROUBLESHOOTING

  Backend won't start?
  → Check if port 8001 is available
  → Install: pip install fastapi uvicorn

  Frontend won't start?
  → Check if Node.js is installed
  → Install: cd thesis-frontend && npm install

  Can't connect?
  → Ensure backend started first
  → Check http://localhost:8001 directly
  → Look at browser console (F12) for errors
